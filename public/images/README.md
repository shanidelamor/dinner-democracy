# Recipe-specific food illustrations

The current library uses `recipes/<recipe-id>.webp`: 51 separate images for the 51 entries, plus four images for the shaved-beef, slaw and two alternate rib preparations. Every current recipe has a unique image path and unique image content. The images were generated for this app from each dish’s actual ingredients, cut, method and sides, then exported as optimized local WebP assets.

They are illustrative food photography, not photographs of the family's previous meals. The three archived entries are labeled concepts, with no claim that a complete historical recipe exists.

The seven older PNG category images in this directory are retained for historical/user-created recipe references. They are no longer the current seeded library images. No external image service or ongoing image-generation API is used by the running app.
